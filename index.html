One-time setup needed

This copy of the app isn't connected to a database yet.
  1. Create a free project at console.firebase.google.com.
  2. Enable Authentication → Email/Password.
  3. Create a Firestore Database.
  4. In Project settings → your apps, add a web app and copy the config object.
  5. Paste it into the firebaseConfig section near the top of this file's code, in place of the placeholder values.
